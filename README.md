# Joma

Joma is a personal finance and budgeting platform designed to help users
track income, expenses, accounts, budgets, and savings across multiple currencies.

## Planned Features

- Secure user authentication
- Multiple financial accounts
- Income and expense tracking
- Multi-currency support
- Monthly budgets and spending analytics
- Savings goals
- Recurring transactions
- Financial reports and CSV exports

## Technology Stack

- Next.js App Router
- React and TypeScript
- Tailwind CSS
- PostgreSQL
- Prisma ORM
- Zod
- Recharts

## Development

Requirements:

- Node.js 24+
- npm
- Git

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open http://localhost:3000.
